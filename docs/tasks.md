# Task List

## Task 1: Shopping Cart Quantity Accumulation

Customers have reported that when they add the same product multiple times to their shopping cart, the total quantity does not update correctly and simply replaces the previous count. Please investigate and fix the issue so that adding the same item again increases the existing quantity rather than overwriting it.

## Task 2: Optimize Product Filtering Performance

Customers have reported that applying filters to the product catalog takes too long and slows down the browsing experience. Improve the filtering mechanism so that filtered results are returned quickly without loading the entire product list at once.
